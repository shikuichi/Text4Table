# Text to Table Lite (テキストから表を作るツール)

半角スペースや改行で区切られたプレーンテキストから、即座にHTMLテーブル（`<table>`）やTSV形式の表を生成する単一HTML完結型の軽量Webツールです。  
フィールドワークでの受信調査結果まとめ、メモ書きの表組み化、ブログ貼り付け用コード作成などに適しています。

---

## 特徴

- **完全スタンドアローン・通信なし**  
  外部サーバーへのリクエストやトラッキングは一切行いません。ブラウザ単体（オフライン環境やローカルファイル直接実行）で安全に動作します。
- **2種類の出力形式に対応**  
  - **HTML方式**: Webサイトやブログにそのまま埋め込める `<table>` コードをコピー。
  - **TSV方式**: GoogleスプレッドシートやMicrosoft Excelへそのまま貼り付け可能なタブ区切りテキストをコピー。
- **自動タイトル判定**  
  1行目の列数がデータ行と異なる場合、自動的にタイトル行（全列結合ヘッダ `colspan`）として処理します。
- **柔軟な配置設定**  
  表全体のレイアウトを「左揃え / 中央揃え / 右揃え」から選択可能。
- **自動保存（LocalStorage）**  
  入力内容や配置設定はブラウザのローカルストレージに自動保持されるため、誤ってタブを閉じても作業内容が失われません。
- **印刷最適化**  
  不要な要素を省き、生成した表を綺麗に印刷・PDF出力できます。

---

## 入力仕様

```text
タイトル行（省略可能）
列見出し1 列見出し2 列見出し3
データ1 データ2 データ3
データ4 データ5 データ6
```

- **列の区切り**: 半角スペース（連続するスペースは1つの区切りとして扱われます）
- **行の区切り**: 改行
- **タイトル行**: 1行目に単一文字列などを置くと、自動で表上部のタイトル枠になります。

### 入力例

```text
関東広域の受信調査(標高地点)
局名 周波数(MHz) 受信状態
NHK-FM 82.5 良好
TOKYO-FM 80.0 微弱
J-WAVE 81.3 良好
```

---

## 使い方

1. `index.html` をPCのブラウザで開きます。
2. テキストエリアにデータを入力またはペーストします。
3. **「表に変換する」** ボタンをクリックします。
4. 下部にプレビューが表示されます。用途に合わせて **「HTML方式でコピー」** または **「TSV方式でコピー」** を押してご利用ください。
